# PCAM Precision Agent Dashboard Design

This document outlines the panels, components, and interactive elements needed to build a visual dashboard for running and analyzing the PCAM Precision Agent benchmarks.

## 1. Global Controls (Header)

The header should contain the primary actions to execute tests and view high-level status.

*   **Buttons:**
    *   **`Run Quick Test (G1)`**: Triggers the fast self-check (`self_check.py --quick`) using seeds 42 and 101.
    *   **`Run Full Evaluation (G3)`**: Triggers the comprehensive benchmark (`run.py` with 5 seeds).
    *   **`Run Stress Test (G4)`**: Executes against the adversarial seeds (503, 1009, 9999).
    *   **`Stop / Cancel`**: Aborts the currently running benchmark.
*   **Status Indicators:**
    *   **Execution State**: Idle / Running (with elapsed time).
    *   **Agent Loaded**: Displays the currently loaded adapter (e.g., `adapters.myteam:Engine`).

---

## 2. Main Scorecard Panel

This panel displays the top-level results required by the hackathon scoring rubric. It should instantly communicate whether the agent is passing.

*   **Retrieval Score**: Large display of points earned (0-70).
*   **Anisotropy Score**: Large display of points earned (0-20).
*   **Total Automated Score**: Sum of the above (out of 90).
*   **Key Aggregates (Cards)**:
    *   **Mean Δ Accuracy**: Expected target ≥ 0.05. Color-coded (Red if ≤ 0, Yellow if < 0.05, Green if ≥ 0.05).
    *   **Min Δ Accuracy (Worst Seed)**: Critical metric; if < 0, triggers the halving penalty.
    *   **Mean Spread Reduction**: Expected target ≥ 10×.
    *   **Min Spread Reduction (Worst Seed)**: Critical metric; if ≤ 1.0, triggers halving penalty.

---

## 3. Per-Seed Breakdown Panel

A data table detailing the performance of the agent on every evaluated seed. This is crucial for diagnosing regressions.

*   **Columns:**
    *   `Seed ID` (e.g., 42, 101, 503)
    *   `Baseline Acc (Π=I)`
    *   `Agent Acc`
    *   `Δ Acc` (Color-coded: Red if < 0)
    *   `Baseline Spread`
    *   `Agent Spread`
    *   `Spread Reduction Ratio` (Color-coded: Red if ≤ 1.0)
*   **Features:** Sortable columns, allowing quick identification of the worst-performing seed.

---

## 4. Analytics & Diagnostics Panel

Visualizations to help debug the mathematical behavior of the agent (like the Hessian spread issue we encountered).

*   **Eigenvalue Spread Chart (Scatter/Box plot):**
    *   Visualizes the distribution of eigenvalues for the baseline ($S_{base}$) vs. the agent ($S_{agent}$).
    *   Helps confirm if the extreme outlier eigenvalues are being successfully suppressed.
*   **Precision (Π) Distribution Histogram:**
    *   Shows the distribution of the 64 precision values generated by the agent across queries.
    *   Helps detect if the precision vector is degenerate (e.g., completely flat at 1.0, or pinned entirely at the 0.1/10.0 clipping bounds).
*   **Query Accuracy by Noise Level:**
    *   Bar chart showing accuracy breakdown at the specific noise levels tested ($p = 0.5, 0.7, 0.8$).
    *   Helps diagnose if the agent fails catastrophically at high noise levels.

---

## 5. Raw Logs / Terminal Output Panel

A scrollable text area that streams the raw `stdout` and `stderr` from the Python subprocess.

*   **Features:**
    *   Auto-scroll to bottom.
    *   `Clear Logs` button.
    *   `Copy to Clipboard` button.
    *   Colorized output matching the terminal execution (e.g., ANSI escape code support for the `⚠` and `✓` symbols generated by `self_check.py`).
